The project consists of an animated cat GIF shown using ASCII characters, built with Python, Tkinter, and Pillow. 

The project was created to experiment with and learn how to do image processing and animation in a visually appealing way. Thus, the project was based on recreating the cat GIF based on ASCII characters instead of traditional pixels. Using GIF processing, ASCII conversion, colour preservation, and animation, the project was brought to life. 

Features include: 
* coloured ASCII art 
* animated GIF playback 
* characters in motion 

How to use it: 
1. Download the zip file 
2. Open the zip file. 
3. Run the code!
